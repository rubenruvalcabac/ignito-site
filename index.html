.NET 10 full-stack framework

Build full-stack .NET applications faster

Ignito is a framework and code generator for .NET. Model your data once, generate a clean, tested backend, and build the UI with ready-made Blazor components.

Get in touch See features

Everything a business application needs

From the database to the screen, with patterns your team can rely on.

Schema-driven code generation

Describe your tables in DBML and the ignito CLI generates entities, repositories, CRUD commands, validation, and migrations.

CQRS by default

Commands and queries with consistent requests, responses, validation, and telemetry. Endpoints and services register themselves.

Four databases, one codebase

Fast Dapper-based data access for SQL Server, PostgreSQL, MySQL, and SQLite, with transactions and optimistic concurrency.

Security and multi-tenancy

Users, roles, permissions, API keys, tenants, invitations, and subscriptions ready for SaaS products.

Blazor UI components

Data grids, forms, dialogs, navigation, address autocomplete, and maps, styled with Bootstrap in light and dark themes.

Ready-made integrations

Blob storage, email templates, image processing, geocoding, and Azure services behind clean abstractions.

1

Model

2

3

4

Build
